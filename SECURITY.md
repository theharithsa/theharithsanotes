# Reporting a security issue

Use [GitHub private vulnerability reporting](https://github.com/theharithsa/theharithsanotes/security/advisories/new). Include the affected route or component, expected and observed behavior, impact, and steps using synthetic data. Keep credentials and private content out of reports.

The site uses Firebase Auth and invitation checks for People and Journal. The publishing API uses scoped credentials. See the [repository security policy](.agents/skills/app-launchpad/references/safety.md) for handling secrets, private media, and telemetry.
