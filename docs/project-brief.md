# Project brief

Project: The Harithsa Notes. Owner: Vishruth Harithsa.

Public personal journal at theharithsa.com, inspired by the editorial design of Gates Notes. Audience: engineers, learners, and readers interested in observability, AI tooling, technology, work and life. Journey: discover a feature, browse/filter/search the notebook, read a complete note, explore projects or connect through existing public profiles.

First release: responsive home/archive/article/about/projects/privacy/404; all 12 existing articles at their original paths; keyboard navigation and empty states; static SEO, RSS and sitemap; supplied Firebase Analytics and Dynatrace RUM, behind consent; private GitHub repository generated from App Launchpad; Firebase Hosting configuration and preview.

Excluded: accounts, a CMS, newsletter database, bookings, comments, payment, privileged browser tokens, backend services, Session Replay, and infrastructure unrelated to static Hosting. External services own their transactions. A production DNS cutover must preserve the existing publication until the new release is verified.
