# Transparent signature

Issue #67. Processed from the owner-supplied handwriting photograph with OpenAI imagegen’s transparent-background edit flow. Prompt: remove paper, lighting tint, texture and dust; preserve the original stroke paths, spacing, detached marks, loops and long underline; add no writing, decoration or backing. Only the processed cutout is committed, not the private input photograph.

Master: `assets/signatures/vish-signature-transparent.png` (1987 x 791). Web delivery: `public/images/vish-signature.webp` (1200 x 478, lossless with alpha). It appears directly below the Meet Vish biography’s closing quote, before interest links and the gallery, at up to 340px wide; CSS changes the ink to a pale tone in dark mode while preserving transparency.
