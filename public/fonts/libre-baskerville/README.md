# Libre Baskerville web fonts

Upstream: https://github.com/google/fonts/tree/main/ofl/librebaskerville
License: SIL Open Font License 1.1, included as OFL.txt.

Variable upright and italic fonts, weights 400-700. Locally subset with fontTools to Latin/extended Latin and common punctuation/currency/arrows, then compressed as WOFF. Full Unicode text still uses system fallback where a glyph is absent. No third-party font request is made by the site.

Source files were downloaded from Google's official font repository during the owner-approved design study. WOFF output is a derivative of those licensed source fonts; file hashes in provenance.json identify the exact source and delivered assets.
